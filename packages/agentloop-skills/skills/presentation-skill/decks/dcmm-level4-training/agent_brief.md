# Agent Deck Brief

Request: 帮我做一个 DCMM 4 评级的培训材料，设计好一点，不要都是文字，生成pptx格式
Profile: balanced (explicit)
Style route: executive-clinical / clinical-executive

## Outcome

Produce a polished professional deck with one focused planning and repair loop.

## Workflow

1. resolve intake or record best-judgment assumptions
2. select one primary style route
3. author source files and required artifacts
4. run render-free QA
5. render, inspect, and repair once
6. run final delivery readiness

## Design Route

Primary preset: executive-clinical
Background system: light clinical report
Composition grammar: clinical-care-pathway
Rhythm candidates: title > standard > scientific-figure > comparison-2col > chart > flow > table
Preferred variants: title, standard, flow, scientific-figure, chart, image-sidebar, comparison-2col, table, stats, kpi-hero
Use the grammar as a coherent starting point, not a mandatory sequence. Keep one page system and borrow at most two bounded secondary moves.

## Completion Rubric

- Every content slide has a clear visual or evidence anchor.
- Slide compositions vary with the argument; the deck is not a repeated card or bullet template.
- Text is readable and no source/footer content intrudes into the body.
- Charts, tables, figures, and images have source or rebuild metadata when required.
- Geometry, rendered visual review, and placeholder checks pass.
- The final PPTX is editable and reproducible from workspace source.

## Context Policy

Start with this brief. Load only the schema, selected style reference, artifact manifest, or QA report needed for the current phase.
Keep the full deck-start packet on disk for audit and recovery; do not paste it into the active prompt.
