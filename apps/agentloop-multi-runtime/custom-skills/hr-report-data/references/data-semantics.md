# 人事法人汇总报表语义

## 物理模型

- 数据源：Eplat `D_A_BSTAHR00_GENERAL2`
- 模型：`M_DWD_BSTAMSHR002`
- 表：`BSTAMSHR00.V_FAWHZHSS0401`
- 粒度：一个组织、一个月份、一个报表指标一行
- 主键语义：`NY + ORG_CODE + REPORT_ITEM_DES`
- 人数值：`MONTH_AMT`，DOUBLE

`NY` 是 `YYYYMM` 字符串。`ORG_CODE` 四位表示含下属单位的全公司口径；对应的四位加 `00` 表示仅总部。两个口径存在包含关系，不得相加。

## 八类指标

| 维度 | 精确 REPORT_ITEM_DES 值 |
|---|---|
| 在岗员工 | `在岗员工人数` |
| 性别 | `男职工人数`、`女职工人数` |
| 青年 | `35岁以下职工人数` |
| 学历 | `大专以下职工人数`、`大专`、`本科`、`硕士`、`博士` |
| 技能等级 | `无技能等级`、`初级工`、`中级工`、`高级工`、`技师`、`高级技师` |
| 职称 | `未评职称`、`初级职称`、`中级职称`、`高级职称` |
| 岗位类型 | `操作岗位`、`技术岗位`、`管理岗位` |
| 党员 | `中共党员人数` |

常用语义映射：青年对应 `35岁以下职工人数`；党员对应 `中共党员人数`；管理类、技术业务类、操作维护类分别对应 `管理岗位`、`技术岗位`、`操作岗位`。

## 分析约束

- 性别、学历、技能等级、职称和岗位类型可在同一组织同一月份内形成分类分布。
- `35岁以下职工人数` 与 `中共党员人数` 是可与 `在岗员工人数` 比较的子集指标；只有两者处于同一组织、同一月份和同一组织口径时才能计算占比。
- 全公司与总部是重叠范围。对比可以并列展示，但不能求和。
- 跨组织汇总可能同时包含母公司与总部或上下级公司；没有互斥范围证据时，不计算集团总人数。
- 源表是月度汇总，不支持个人级解释、去重或画像。
