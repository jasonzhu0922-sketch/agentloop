# 人事报表分析方法

## 单月事实

同一 `month + organization_code + metric` 的记录先检查重复，再报告人数。若出现重复行，分析器会合并并给出重复计数；交付时必须披露该数据质量限制。

## 分类分布

只有性别、学历、技能等级、职称和岗位类型的全部定义子项均已取得时，才计算各项占该维度合计的比例。维度合计用于结构分母，不等同于在岗员工人数；数据口径可能使二者不一致。

## 子集率

`35岁以下职工人数 / 在岗员工人数` 和 `中共党员人数 / 在岗员工人数` 只在相同月份、相同组织代码且在岗人数大于零时计算。

## 月度变化

同一组织代码、同一指标至少覆盖两个月时，计算首月到末月的绝对变化和相对变化。只描述汇总人数变化；不能据此推断入职、离职、调动或因果关系。

## 组织排名

排名按月份、指标和组织口径分组。四位全公司代码与 `XXXX00` 总部代码永远分开排名。排名说明值的相对顺序，不证明绩效或管理质量。

## 禁止聚合

组织层级可能重叠。除非另有互斥范围证据，不对多组织求总人数，也不把全公司与总部相加。
