# 平台数据标准管理业务架构技能

本技能用于识别和管理数据标准管理的业务流程、业务动作，沉淀承载页面的业务定位与数据链路，帮助智能体理解相关页面之间、页面展示的数据之间、数据库表之间的逻辑关系，从而协助用户使用页面功能、理解数据。

> **AgentLoop 接入边界**：本发布副本仅提供只读业务架构解释。不得通过页面、数据库、浏览器自动化或未审计的 MCP 新增业务对象、变更标签或发布/下架数据标准。

> **协同网络**：本体语义网业务架构（网络 4）
> - 成员：业务架构开发技能（元技能/框架，定义规范）、本技能（数据标准管理实例）、集团投资管理业务架构技能、集团财务管理业务架构技能、平台数据质量管理业务架构技能、超级智能体平台管理业务架构技能、数据资产管理业务架构技能
> - 一致性约束：业务流程/动作/工具映射规范、SKILL.md 结构规范（两段主结构+可选页面使用向导+可选业务规则）、页面使用向导格式规范、业务规则章节格式（BR-NN）、业务架构 RDF 镜像规范（已启用：域编码 dsm1，rdf/dsm1.ttl + TBox ontoflow_baxx.ttl，SKILL.md 为单一事实源，四步门卫）
> - 变更同步：开发技能变更规范 → 本技能同步更新
> - 跨网络协同（↔ 网络 9 XDATA 平台使用助手）：本技能沉淀页面的**业务视角**（角色/数据链路/页面关系）；页面**操作细节**（DOM 结构/提取技巧/操作坑）归 XDATA 用户手册查询技能与浏览器操作技能，互相引用不复制

## 业务流程识别

### 1. 数据标准基础管理
- **名称**：数据标准基础管理
- **描述**：在治理中心维护数据标准基础数据（业务对象）的流程——按数据分类组织、查询与新增业务对象，形成全量编辑态基础数据。承载页面：业务对象管理页（BEDF15）。

#### 业务动作1
- **名称**：查询业务对象
- **描述**：按数据分类（分类树）或条件（标识符/英文名/中文名/制定者等）检索业务对象基础数据。

#### 业务动作2
- **名称**：新增业务对象
- **描述**：在指定数据分类下创建新的业务对象，录入英文名/中文名/制定者/制定组织/数据持有方等基础属性。

### 2. 数据标准目录发布
- **名称**：数据标准目录发布
- **描述**：将基础数据标准打上资产标签并发布到数图数据标准目录的流程——通过标签体系控制目录上架范围（打上「推荐」标签的对象才上架；标签变更待下周期同步更新目录）。承载页面：数图·数据标准目录页（查询）等。

#### 业务动作1
- **名称**：查询数据标准目录
- **描述**：在数图数据标准目录按标准分类树、资产类型（业务对象/数据元/业务术语）与条件检索已上架的数据标准。

#### 业务动作2
- **名称**：给基础标准打标签发布到目录
- **描述**：在数图数据标准目录页面上，为基础数据标准（业务对象）打上资产标签（推荐/注销/暂时保留），打标结果决定该标准是否写入目录表、是否在数图数据标准目录上架。承载页面：数图·数据标准目录页（与查询目录同一页面）。

## 页面使用向导

### 页面1：业务对象管理页
- **所属系统**：数据平台（XDATA，治理中心 xdata-standard-admin，eplat.baocloud.cn）
- **页面编码与入口**：`BEDF15`，数据中台 → 治理 → 业务对象管理；直达 `https://eplat.baocloud.cn/xdata-standard-admin/web/BEDF15`（注意：手册中的 BEDF1502 是菜单内跳转子页编码，不能直接打开）
- **业务角色**：承载流程1（数据标准基础管理）的查询业务对象、新增业务对象两个动作；是数据标准基础数据的全量编辑态入口（含已注销/未生效对象）
- **数据链路**：读写业务对象基础表 `T_ODS_TBEDF15`（UUID 前缀 DY_BO）；关联数据分类表 `T_ODS_TBEDF32`——关联字段为 `OBJECT_RANGE = TBEDF32.UUID`（唯一 100% 有效关联；TBEDF15.AREA_ID/AREA_NAME 含 36 条陈旧旧口径值，勿用于分类关联）；左侧分类树按 TBEDF32 层级组织
- **关联页面**：上游无；下游为数图·数据标准目录页（基础数据经打标后上架展示）

### 页面2：数图·数据标准目录页
- **所属系统**：数据平台（XDATA 数图，中国宝武数据资产 xdata-assets-manager，eplat.baocloud.cn）
- **页面编码与入口**：BEXY5201（数图首页）→ 顶部导航「数据标准目录」子页面（内部子页面，无独立编码）
- **业务角色**：承载流程2（数据标准目录发布）的查询数据标准目录、给基础标准打标签发布到目录两个动作；既是已上架数据标准的目录展示态入口（不含注销/暂时保留对象），也是打标操作（控制上下架）的工作页面
- **数据链路**：读数据标准目录表 `T_ODS_TBEXY41`（UUID 与 TBEDF15 同为 DY_BO 前缀，可直接按 UUID 对齐；查业务对象须加 `STANDARD_TYPE='businessObject'`；按 `AREA_ID` 中文路径如「财务->应付」直筛分类）；打标操作写 `T_ODS_TBEDF1417`（打标关系）＋`T_ODS_TBEDF1413`（标签主数据），经按标签过滤写入 TBEXY41
- **关联页面**：上游为业务对象管理页（其基础数据打标后写入目录）

### 页面关系与数据流总图

```
【业务对象管理页 BEDF15】                                【数图·数据标准目录页】
   查询/新增业务对象                                        查询数据标准目录 / 给基础标准打标签
        │                                                       │
        ▼                                                       ▼
  T_ODS_TBEDF15（基础） ──打标──> T_ODS_TBEDF1417（关系）＋T_ODS_TBEDF1413（标签） ──按标签过滤写入──> T_ODS_TBEXY41（目录） ──展示──> 目录页
  （全量编辑态，含注销对象）        （推荐/注销/暂时保留）                （仅「推荐」写入；标签变更待下周期同步）
```

- 操作细节（DOM 结构/iframe 穿透/Kendo 翻页/分类树勾选等）：引用 XDATA 用户手册查询技能（`shutu-xdata-user-manual-query`，其本地沉淀含两页面实测技巧）与浏览器操作技能（`shutu-xdata-browser-ops`）

## 业务规则

### BR-01 数据标准目录数据链路
- **规则描述**：`BEDF15（基础）→ 打标签 → 按标签过滤写入 TBEXY41（目录）`——治理中心维护业务对象基础数据（TBEDF15）；数图侧通过资产标签体系（TBEDF1417 打标关系 + TBEDF1413 标签主数据）打标；目录表 TBEXY41 在**写入时**按标签过滤，**打上「推荐」标签的对象才进入目录**（注销/暂时保留/未打标均不写入，非查询时过滤）；**标签变更（含取消标签）不即时生效，待下个周期同步数据时更新目录**——同步前目录可能残留已取消标签的对象
- **错误做法**：以为数图目录是查询时过滤；直接拿基础表 TBEDF15 全量当目录口径；用 TBEDF15 的状态字段（已生效/未生效）判断数图上下架；以为标签变更立即反映到目录（目录按周期同步更新，存在滞后窗口）
- **正确查法**：查基础/编辑态看 TBEDF15；查上架目录看 TBEXY41（业务对象加 `STANDARD_TYPE='businessObject'`）；判断上下架以标签为准（推荐=上架，注销/暂时保留=不上架），目录因周期同步可能短暂滞后于最新标签状态。附注：TBEDF15 的状态字段与标签体系相互独立（存在「已生效」却打了注销标签的对象），勿混用
- **来源会话**：2026-08-19 数据标准管理探索会话（财务→应付 11 − 2注销 − 1暂留 = 8 闭合验证；本体语义网 + 数智域 SQL 实证）；2026-09-01 全量三方验证（13 项 SQL 断言 + 五分类闭合 + 双页面名单一致；实测发现的无「推荐」标签对象仍在目录现象，经用户确认属「仅推荐写入 + 周期同步滞后」的正常表现，见任务目录验证报告）
