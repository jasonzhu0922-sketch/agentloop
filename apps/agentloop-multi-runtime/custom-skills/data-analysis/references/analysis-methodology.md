# 分析方法与降级

从用户问题和实际结果形态选择方法，数字应能回溯到当前场景的数据集和确定性计算。

- 汇总与排名：确认指标、单位、过滤条件、粒度和比较集合一致且覆盖完整；区分求和、计数、去重计数、均值和中位数。快照不应跨日期相加，除非业务口径明确支持。
- 趋势：按真实时间字段排序，说明实际覆盖、粒度与缺口。一个观测日只能描述当日，不能判断趋势；同日多个值不得擅自选代表值。同比或环比应使用可比区间，增长率分母为零时说明不可计算。
- 跨数据集比较：先核对定义、单位、频率、对象范围、时间交集和连接粒度；不满足时分别描述，不计算差值、比率或排名。数据源并列展示不等于存在可 JOIN 的业务关系。
- 异常、相关和统计：明确基线、规则及样本量；异常值不能自动删除，相关不等于因果。统计推断仅在研究设计和方法前提成立时使用，明确不确定性。
- 结果检查：区分观测、派生计算和业务解释。模型摘要与数值冲突时回到完整数据和口径；不拿一页预览或模型摘要替代完整结果。
