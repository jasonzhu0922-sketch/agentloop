# ODS 单表建模分析 — 批量任务文件格式

批量任务文件用于一次性指定多张待分析表，支持并行 Agent 批量处理。

---

## 文件结构

```markdown
# ODS 单表建模分析批量任务

## 执行约定

- MCP 查询统一使用：`data_domain=CW`
- 单表分析规范统一遵循：本技能（shutu-ods-analysis）
- 报告默认输出目录：`output`
- 每张表单独产出一个 Markdown 报告，不合并多表内容

---

## 任务：{SCHEMA}.{TABLE_NAME}

- 输出文件：`output/{SCHEMA}_{TABLE_NAME}_分析报告.md`
- 数据域参数：`CW`

```text
请使用 ods-analysis 技能的最新规范，对下列表做单表建模分析，并严格区分"查询事实"和"建模推断"。

约束要求：
- MCP 查询统一使用：data_domain=CW
- 目标表：{SCHEMA}.{TABLE_NAME}
- 输出文件：output/{SCHEMA}_{TABLE_NAME}_分析报告.md
- 结果必须围绕单表展开，不要扩展为 Schema 总览
- 必须包含：基本信息、关键字段、扩展与预留字段、直接关联表、关系图、样例与关键分布、建模结论
- 总记录数必须使用 COUNT(*)
- 直接关联表只保留 2~10 张最相关的表（当一张表确实应该有不少关联关系时，上限可定为 20 张）
- 若字段含义、状态码或占位值不明确，明确标注"待补数据字典/业务口径"
- 若系统备注为空，请基于字段和样例自行判断对象语义
```

---

## 任务：{SCHEMA}.{TABLE_NAME_2}

...（重复上述格式）
```

---

## 使用方式

1. 按上述格式创建批量任务文件（如 `prompts/ODS单表建模分析_批量任务.md`）
2. 将文件路径提供给 Claude，要求按任务文件批量生成
3. Claude 会将表按前缀分组，使用并行 Agent 同时处理多组表
4. 所有报告输出到指定目录
