云端模型配置

读取生产配置，编辑 Provider、模型参数和 API Key，保存并应用到云端 Runtime。

Provider 与模型配置

可读取生产配置或导入文件。编辑后点击「保存并应用到生产」才会更新服务器。

API Keys留空保留服务器原 Key；填写只替换对应变量，其他环境变量保留。
尚未载入配置

保存时会校验、备份并重建云端 Runtime。请先暂停新任务并等待已有任务结束。导入 runtime.env 表示完整替换环境文件，必须保留仍需使用的其他变量；不导入则保留服务器文件并合并填写的 Key。

重新加载云端 Runtime

将服务器上已保存的配置应用到所有云端 Runtime。请先暂停新任务并等待现有任务结束；本页尚未部署的编辑内容不会应用。

重新加载后将逐个检查 Runtime 就绪和有效模型配置。
