LOCAL RUNTIME AGENT

让 AgentLoop 在本机运行

安装后，将本机能力连接到你的工作区。你可以为当前设备，也可以为其他电脑下载安装包。

选择安装包

正在识别设备，你也可以直接选择安装包。

正在获取安装包…

不确定 Mac 的芯片类型？打开苹果菜单 →「关于本机」，查看“芯片”或“处理器”。

历史版本

可按需要选择旧版本。与当前工作区协议不兼容的版本会单独标注。

下载之后

  1. 01
    运行安装器

    打开下载的安装包，按系统提示完成安装。

  2. 02
    启动 Agent

    打开 Local Runtime Agent，确认托盘图标已出现。

  3. 03
    回到工作区配对

    点击“本机能力”，连接你的设备。

设备识别仅用于推荐，安装包由你选择。
