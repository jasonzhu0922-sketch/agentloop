本机 Providers
添加 Provider 后，使用 JSON 配置服务连接和模型列表。

填写 JSON 数组；每个对象表示一个模型。可添加多个模型，也可先保留空数组 []。

配置字段说明

Provider 必填：key（唯一 ID）、displayName、baseUrl；新增时填写 apiKey。基础地址例如 https://api.example.com/v1。

模型必填：key（本机唯一 ID）、displayName、providerModel（上游模型名称）。protocol 可选 responses（默认）或 chat-completions。

容量：contextWindowTokens 默认 128000；maxOutputTokens 默认最多 8192，必须小于上下文窗口。

采样：temperature 为 0–2，topP 为 0–1；仅配置上游支持的参数，省略时不发送。

Responses：reasoningEffort 为 none / low / medium / high；reasoningSummary 为 auto / detailed；reasoningEncryptedContent 为布尔值。

Chat Completions：支持扩展的服务商可配置 thinkingMode（enabled / disabled）、thinkingEffort（low / medium / high）、planningThinkingMode 和 chatTemplateKwargs（对象）。

请求：timeoutMs 默认 120000；maxAttempts 默认 3（含首次，范围 1–5）；retryDelayMs 默认 250。时间单位为毫秒。

高级选项：toolChoiceMode（native / constrained-as-auto / named-as-required）、runtimeContextPlacement（system / user-envelope）、reasoningVisibility（visible / hidden）。
