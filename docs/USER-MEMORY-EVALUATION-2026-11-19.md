## 成本与版本边界

- 隔离评估为从空经验库开始的调试重放，没有导入完整历史经验库；中途修改实现，并仅恢复失败样本，因此也不是固定版本、严格时间顺序的纵向对照实验。
- 末次报告累计 52 次已记录用量的模型调用，输入 727,347 token、输出 129,208 token。包含调试和重试，未报告或中断的用量无法补造。该数值不能证明成本下降；也不能和原线上不同批次的用量直接比较效率。
- 一个营业收入局部修正只返回了 523 个输出 token，保留此前 4,459 token 输出中的有效部分；它只证明局部输出可减少重写，不能证明整条链路总成本下降。
- 本轮最后补齐了关系局部修正的命题、合并决定和范围上下文，并将 reinforce 的局部关系修正限制为 support 或明确撤回。该最后修正已通过程序回归，**尚未再次调用真实模型复验“两金”样本**。没有追加整批重放来掩盖剩余失败。
- 报告包含部分评估轮次的源码指纹；增加版本记录之前的尝试没有完整版本归属。不得把所有接受结果归为最终同一版本的通过率。
