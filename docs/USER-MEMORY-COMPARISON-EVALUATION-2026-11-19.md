## 第一处断点与本轮改造

首轮 3 个失败样本已经有可接受的独立归纳，但历史融合要求模型再次生成整份经验，同时维护命题位置、知识 ID、评价引用和组级合并决定。第二次生成会改写已经归纳好的命题，关系随之错配。

有历史知识时，现改为 `agentloop.knowledgeComparison/v1`：

- 当前独立归纳的命题、参数、范围、引用及数组位置固定。第二次模型输出只包含组关系、简短理由、逐知识关系及其支持评价。
- 模型继续判断任务族、同一命题、修订和反驳；程序提供精确身份、结构上的可能选项，并校验来源、范围和一对一映射。不接受整份重写结果作为兼容输入。
- 支持评价默认使用所属命题的引用；显式引用必须是该条原引用的子集，不能改成历史来源或其他命题的证据。
- 路径评价数量在输出契约中固定为当前路径步数，其他知识各一条。结构错误指出具体字段及实际数量，只重生成较小的比较结果；已接受的独立归纳继续复用。
- 方法、环境认知、处置规则是不同知识角色，不能以修订关系共用身份。类型不同的独立新命题使用新身份，不能覆盖旧的失败处置知识。
- 比较选项也计入原有输入预算；仍按相关性减少历史上下文，保留当前证据，沿用已有批处理和超量分窗。没有增加同步归纳入口或每条日志的总结调用。

另外修复了保留原组时的新知识丢失：新独立条目保留自己的命题、参数与支持，不要求出现在组的固定正文中。后续可以按稳定身份再次比较并发布。支持同义改写时保留原参数定义；修订仍清空旧验证支持。

## 下一处结构限制

当前知识关系仍要求目标属于所选择的任务组，新任务组不能同时支持另一组的独立知识。任务整体不同、子方法相同的情况因此仍可能分散支持。真实样本中均选择新组，也需要继续复查其语义合理性，尤其不能仅凭主体、期间或指标参数变化就划分任务族。

下一阶段先把独立知识的比较与累计从任务组合并中分离：任务组保留案例与完整轨迹，独立条目按自身条件和操作检索候选，由模型判断是否同一方法；程序维护稳定身份、多来源支持与来源修订约束。先验证跨组独立累计和真实发布，再验证执行中的召回、引用与调用节省。不得通过复制旧支持、放宽成熟条件或把继承结果计为新执行获得收益。
